# Logo and colors

The logo is one cell of the sea sparkle (*Noctiluca scintillans*). A round cell glows blue from a white nucleus at its center, and one tentacle hangs from its bottom.

| Name | Color | Use |
|---|---|---|
| Abyss | `#050A16` | Social image background (top) |
| Deep | `#0B1F3A` | Social image background (bottom), logo edge |
| Cell | `#1E4D78` | Inside the cell |
| Glow | `#5CE1E6` | Primary color. Tentacle, links |
| Spark | `#8FF3F7` | Light particles |
| Foam | `#E6FDFF` | Text, nucleus glow |
| Mist | `#9CC7E4` | Secondary text |

The cell's gradient passes through `#3FA9C9`.

## Files

- `assets/logo.svg`: the logo. It has no background and works on dark and on white.
- `assets/social-2x1.png`: the GitHub social preview.
- `assets/social-16x9.png`: the image at the top of the README.
- `assets/gen-social.py`: generates the social images. Its header shows how to run it.
